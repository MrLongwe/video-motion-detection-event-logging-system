# Real-Time Video Motion Detection and Event Logging System

A Python-based computer vision project that detects motion in live video streams and automatically records timestamped events for later review.

## Features

- Real-time video processing
- Motion detection
- Event logging
- Timestamped evidence capture
- Modular architecture
- OpenCV-based implementation

## Technology Stack

- Python
- OpenCV
- NumPy

## Project Status

In Development

## Planned Features

- Motion detection engine
- Event image capture
- Timestamped event logs
- IP camera support
- Configurable sensitivity thresholds
